# Aaditya Raj — Portfolio Website

A minimal, aesthetic portfolio website for **Aaditya Raj (Aadir0)** — Computer Science Student & Indie Game Developer.

## 🌟 Highlights & Features

- **Warm Cream Minimalist Aesthetic**: Clean typography, zero heavy cards or bulky rounded borders.
- **Interactive Entrance Mini-Game (Three.js)**:
  - Appears on initial website load.
  - Player controls a low-poly speeder to score **100 integer points** (collecting yellow crystals and avoiding obstacles) to unlock access to the website.
  - Defeat allows instant replay; victory grants entry with celebratory audio.
  - Can be replayed at any time using the header shortcut.
- **Exact 4 Sections**:
  1. **About**: Personal journey, Student Ambassador at GDAI, winner of Just a Hackathon.
  2. **What I Know**: HTML, CSS, C, C++, C#, Java, Go, Unity, Aseprite, Blender, with focus on 2D proficiency and ongoing 3D learning.
  3. **Projects**:
     - *Time Traveler* (Winner of Just a Hackathon)
     - *Nightmare - A fairy tale* (Geek-N-Jam Game Jam)
     - *DriftIT* (2D top-down multiplayer drifting game)
     - *Strange Rooms* (Brackeys Game Jam)
     - *ILLegal Moves* (Rule-bending precision platformer)
     - *The Last Train* (Atmospheric exploration experience)
     - *Dragons Quest* (2D platformer milestone)
  4. **Contact**: Quick-copy email `aadisingh3217@gmail.com`, direct social links (GitHub, Itch.io, LinkedIn, Instagram), and minimal contact form.

## 🚀 Running Locally
Open `index.html` in any browser or run:

npx serve .
